# LectureFlow · Практическая работа № 5

Конструктор учебных промптов. Выберите один из семи шаблонов, укажите тип материала и сформируйте текст. Для поиска можно одновременно задать часть заголовка и категорию. «Подробнее» открывает описание шаблона, «Сбросить» возвращает все семь карточек.

## Локальный запуск

В терминале из корня этой ветки выполните `python -m http.server 8000 --bind 127.0.0.1` и откройте <http://127.0.0.1:8000/>. Также можно открыть этот каталог в VS Code и выбрать **Open with Live Server** для `index.html`.

Семь карточек входят в исходный HTML. Обработчики в `js/script.js` меняют список, открывают диалог и собирают промпт в браузере. Кадры работающего сайта и короткий GIF входят в проверенный архив LectureFlow_HW5_Verified.zip. Автономный запуск и все семь пресетов проверены на ПК и физическом POCO F6. Опубликованный адрес этой версии отсутствует.
