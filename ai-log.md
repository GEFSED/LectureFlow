## Как объяснить свой код

Схема: **событие → обработчик → проверка → изменение DOM**.

- Ввод символов в `#template-search` вызывает `applyFilters()`.
- Изменение `#template-category` вызывает ту же `applyFilters()`, поэтому два фильтра не конфликтуют.
- `forEach()` проходит по карточкам. `includes()` проверяет название, `dataset.category` — категорию. Свойство `hidden` скрывает неподходящие элементы без удаления из DOM.
- `templateCount.textContent` сообщает количество найденных карточек; `templatesEmpty.hidden` включает пояснение, если совпадений нет.
- При нажатии «Подробнее» обработчик берёт текст текущей карточки и открывает `showModal()`. Кнопка «Закрыть» вызывает `close()`; Escape поддерживается нативным `dialog`.
- При выборе шаблона из диалога используется уже существующий обработчик кнопки «Выбрать», поэтому функция генерации не дублируется.
