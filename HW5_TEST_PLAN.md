# LectureFlow — ДЗ № 5: проверка и демонстрация

## Реализовано в ветке
- Живой поиск по заголовкам семи шаблонов (с нормализацией пробелов и регистра).
- Фильтрация по категориям: конспекты, изучение материала, практика и проверка.
- Общая функция `applyFilters()`, которая учитывает оба условия; счётчик, пустое состояние и сброс.
- Одно доступное нативное `<dialog>` для подробностей каждого шаблона, закрытие кнопкой и Escape.
- Сохранены прежние выбор шаблона, генерация и копирование промпта.

## Автоматические статические проверки при обновлении
Девять исходных структурных проверок — PASS. Это не браузерные end-to-end тесты.

## Ручные тесты (провести в Chrome и на телефоне)
- [ ] При открытии показано 7 карточек, счётчик «Найдено: 7».
- [ ] Поиск «КОНСПЕКТ» и «  конспект  » оставляет подходящую карточку.
- [ ] Очистка поиска восстанавливает все 7 карточек.
- [ ] Выбор «Изучение материала» оставляет две карточки.
- [ ] Комбинация «конспект» + «Практика и проверка» показывает 0 и сообщение.
- [ ] Изменение категории после ввода и ввода после категории даёт одинаковый результат.
- [ ] Сброс возвращает пустой поиск, «Все категории», 7 карточек.
- [ ] «Подробнее» у двух разных карточек показывает разные заголовки/описания.
- [ ] Закрытие работает и кнопкой, и клавишей Escape; Tab не уводит за пределы модального окна.
- [ ] После 10 повторных открытий нет двойных обработчиков/сбоев.
- [ ] Выбор шаблона, сборка промпта и копирование продолжают работать.
- [ ] Проверены ширины 375, 390, 768, 1024 и 1440 px; горизонтальной прокрутки нет.
- [ ] DevTools → Console не показывает критических ошибок.
- [ ] На опубликованном адресе работает тот же код.

## Для сдачи преподавателю
1. После проверки объединить ветку с `main` либо настроить публикацию тестовой ветки отдельно.
2. Проверить публичный URL сайта на телефоне.
3. При необходимости сделать GIF или запись до 2 минут: поиск → категория → пустое состояние → сброс → два диалога.
4. Показать `ai-log.md` и объяснить: событие → обработчик → проверка → изменение DOM.
5. Записать реальные результаты тестов, проблемы и исправления в журнале ИИ.
