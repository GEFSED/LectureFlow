## HTML

| Элемент | Где используется | Что означает |
| --- | --- | --- |
| `<header>` | Вверху | Шапка сайта с названием LectureFlow и навигацией |
| `<nav>` | В шапке | Ссылки на разделы страницы (`#about`, `#templates`, `#result`, `#builder`) |
| `<main>` | Центральная часть | Основное содержимое сайта (вне шапки и подвала) |

| `<aside>` | `.preview`, `.checklist` | Дополнительный контент рядом с главным сценарием |
| `<form>` | `#prompt-form` | Настройка типа материала, цели, подробности и остальных параметров |
| `<label>` + `<select>` | В форме | Связанные подписи и выпадающие списки |
| `<footer>` | Внизу | Авторство и название проекта |

**Вопрос преподавателя: «Где `article` и что его форматирует?»**  
Ответ: внутри `section#templates` есть контейнер `<div class="cards">`; в нём семь `<article class="card">`. `article` — семантический HTML-тег отдельной карточки, а её **внешний вид задаёт CSS-класс `.card`**; `.card-top`, `.card-icon`, `.card-tags` отвечают за внутренние части карточки.

## CSS — определения на примере проекта

- `:root { --color-primary: #635bff; ... }` — общие переменные для повторяющихся цветов, отступов и скруглений; `var(--color-primary)` считывает значение.
- `.header-content { display: flex; justify-content: space-between; align-items: center; }` — раскладка навигации вдоль главной (горизонтальной) оси, выравнивание по поперечной.
- `.cards { display: grid; grid-template-columns: repeat(4, minmax(0, 1fr)); }` — двумерная сетка из четырёх одинаковых гибких колонок на большом экране.
- `.card { display: flex; flex-direction: column; }` — внутри карточки элементы идут вертикально; `margin-top: auto` у тегов прижимает нижнюю часть карточки вниз.
- `.fields { display: grid; ... }` — двухколоночная форма; на мобильном каждая настройка становится отдельной строкой.
- `padding` — внутреннее расстояние от содержимого до границы элемента; `margin` — внешний отступ до соседних элементов; `border` — рамка.
- `box-sizing: border-box` — заданная ширина включает рамку и внутренние отступы; предотвращает неожиданный рост карточки.
- `border-radius` — скругление. `.result-panel` и `.checklist` имеют одну переменную `--radius-panel`: 24px на desktop, 18px на mobile. Преподаватель отдельно просила это выровнять.
- `@media (max-width: 600px)` — CSS-правила, применяемые только на экранах до 600px: меняют сетку на 1 колонку, скрывают desktop-nav и показывают мобильное меню.
- `:hover` — курсор над кнопкой; `:active` — момент нажатия; `:focus-visible` — видимая обводка при клавиатурной навигации; `:disabled` — неактивный элемент.
- `1fr` — доля свободного пространства внутри сетки Grid; `gap` — промежуток между ячейками/элементами.

## Небольшой JS, оставшийся от ДЗ №3

Кнопка `choose-template` читает `data-goal`, `data-detail` и другие `data-*` атрибуты карточки, выставляет значения полей, выделяет выбранную карточку. На `submit` формируется текстовый промпт из параметров и показан в `textarea#prompt-output`. При изменении поля старый текст очищается, поскольку параметры уже другие. На `copy-button` — попытка копировать в буфер, иначе выделяется текст для Ctrl+C. Новую серверную обработку или ИИ-функцию пока не делали.
