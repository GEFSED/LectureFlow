### Точные ограничения

- Chrome/Chromium не смог открыть локальный URL из-за `ERR_BLOCKED_BY_ADMINISTRATOR`. Для Playwright использовались `page.set_content()` и `page.route()`, возвращающий JSON с кодом 200/404; `fetch()` запускался реальным скриптом, но ответы были перехвачены.
- При специально смоделированной ошибке HTTP 404 браузер выдаёт ожидаемую диагностическую ошибку. **Console без ошибок подтверждена только для нормального успешного сценария**.
- Нет полного E2E через реальный локальный HTTP, теста на физическом телефоне **для ДЗ № 6**, Firefox, Safari или опубликованной версии. Не обозначать эти пункты как PASS.
