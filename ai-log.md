# Журнал работы с Codex · 26 ноября 2026 года

Пользователь поручил выполнить локальное ТЗ, сначала сравнить версии, восстановить архитектуру из видеолекции и провести независимую проверку на своём телефоне. Источником конкретных устных требований служит их изложение в предоставленном ТЗ. В каталоге были три ZIP и само задание. Отдельная запись занятия и исходный текст лекции отсутствовали.

Codex прочитал архивы средствами Python, сверил SHA-256, извлёк в рабочий каталог шесть файлов сайта HW6 и сравнил их с исправленным HW5. Отдельные документы для HW6 в предоставленный ZIP не вошли. README, этот журнал и тест-план составлены для текущего пакета.

В исходном скрипте поиск менял hidden у DOM-элементов, а пустой массив отклонялся как некорректная структура. Исправление в js/script.js хранит модели в allCards, передаёт результат отбора в renderCards, восстанавливает выбранный ID при построении карточки и различает виды сбоев загрузки. Проверка пресета теперь сверяет значения с допустимыми опциями формы. Модальное окно получает текст из соответствующей записи JSON.

Независимые сценарии написаны для Playwright и CDP. Тестовые HTTP-ответы 404, разрыв, повреждённый JSON, повтор ID, неизвестное значение пресета и пустой массив создавал сервер QA. На Windows первое утверждение о буфере обмена дало ложные отказы из-за CRLF. Трасса показала, что содержимое текста совпало после нормализации переносов. На Android системный ввод ADB получил отказ INJECT_EVENTS. В Chrome использованы касания через CDP. При первом касании кнопки генерации страница ещё прокручивалась. В повторном прогоне сценарий дождался стабилизации и проверил цель касания. Для буфера Android сравнение сделано по исходному тексту события paste до преобразования переносов однострочным полем.

Для сравнения промптов использованы семь ожидаемых текстов из fixed/1440-prompt-*.txt в архиве HW5. Сравнения заново выполнены на запущенном HW6. Тексты совпали для всех семи пресетов на ПК и телефоне. При копировании Anki на Android событие вставки было доверенным, получен полный текст промпта.

Итог независимой проверки — **PASS**. 351 PASS, 0 FAIL, 0 BLOCKED, 0 MANUAL_REQUIRED, 0 NOT_TESTED. Ручной ввод Anki зафиксирован в поиске при открытой экранной клавиатуре. Осталась одна карточка «Карточки Anki».
