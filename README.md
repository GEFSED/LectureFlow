## О проекте

LectureFlow — учебный конструктор промптов. Пользователь выбирает тип материала, цель и параметры. Сервис создаёт **текст запроса** для сторонней нейросети, **а не готовый конспект**.

**Figma:** https://www.figma.com/design/l932b3iHuUb68Kofhw2Est

## Структура

- `index.html` — содержание страницы, форма, 7 карточек, блок результата.
- `css/style.css` — минимальное оформление и адаптация под телефон.
- `js/script.js` — выбор шаблона, составление текста запроса, копирование.
- `data/data.json` — заготовка для будущего занятия, **сейчас не используется**.
- `assets/images/` — место для будущих изображений, **сейчас нет изображений**.

## Функции

1. Якорные ссылки переходят к нужным разделам страницы.
2. Форму можно заполнить вручную, два обязательных поля проверяет браузер.
3. Кнопка на любой из семи карточек подставляет готовую цель, подробность и дополнительные параметры. Выбранная карточка выделяется, а параметры можно изменить.
4. Кнопка «Сформировать промпт» создаёт текст по параметрам.
5. Кнопка «Скопировать промпт» копирует полученный текст. Если параметры изменены, старый результат очищается.
6. Дополнительный раздел добавляется только при его выборе. Отдельные быстрые параметры работают независимо.
7. Справа показана памятка перед использованием результата (не автоматическая проверка).

**Ограничения:** пока нет анализа загруженных файлов, отправки на сервер, ИИ API и фильтрации по JSON. Поле файла только позволяет выбрать документ на устройстве; сам документ пользователь должен отдельно приложить во внешней нейросети. Это учебный HTML-каркас с небольшими интерактивными элементами, не готовый облачный ИИ-сервис.

## Запуск

1. Распаковать архив и открыть папку `LectureFlow_HW3` в Visual Studio Code.
2. Установить расширение **Live Server** (Ritwick Dey).
3. Открыть `index.html` → **Open with Live Server**.
4. Проверить ссылки, форму, шаблоны и копирование.
