## Назначение

LectureFlow — **конструктор текстовых промптов** для дальнейшей работы с учебными материалами в выбранной пользователем внешней нейросети. Он **не анализирует и не загружает файл в нейросеть автоматически**, не формирует готовый конспект. Выбранный локальный файл не отправляется на сервер, его необходимо отдельно приложить к скопированному промпту во внешнем сервисе.

Работа №4 продолжает HTML-каркас работы №3. Реализован **статичный адаптивный интерфейс** по согласованным экранам Figma (`03_FINAL`: Desktop Final 1440 и Mobile Final 375); уже существующее небольшое поведение на JavaScript сохранено.

## Что изменено для ДЗ №4

- Отдельная таблица стилей `css/style.css`, корректно подключенная из `index.html`.
- Переменные `:root` для основных цветов, размеров, отступов, шрифтов и скруглений; общая блочная модель `border-box`.
- Единая визуальная система для шапки, главного экрана, формы, семи карточек, результата, памятки и подвала.
- **Flexbox:** шапка, карточки, кнопки/чипы, строка действий. **Grid:** форма, каталог карточек, композиция главного экрана и результата.
- Несколько медиазапросов: desktop и промежуточная ширина, планшет, mobile 375–390 px; на телефоне карточки перестраиваются в одну колонку и появляется адаптивное меню.
- Состояния элементов `:hover`, `:active`, `:focus-visible`, `:disabled`, состояние невалидных полей `:user-invalid` (там, где поддерживается браузером); выделение выбранной карточки через `.selected`.
- У блока результата и чек-листа **одинаковый радиус**: `24px` на большом экране и `18px` на мобильном — исправление замечания преподавателя.
- Сохранены выбор всех 7 пресетов, изменение параметров, создание текстового промпта, очистка устаревшего результата и возможность копирования.

## Как запустить

1. Скачайте ZIP основной ветки `main` на GitHub или склонируйте репозиторий и откройте папку в VS Code.
2. Установите **Live Server** (при необходимости), откройте `index.html` через **Open with Live Server**.
3. Проверьте навигацию, семь шаблонов, настройку и формирование/копирование промпта.
4. В Chrome/Edge откройте DevTools (`F12`), включите Device Toolbar (`Ctrl+Shift+M`) и проверьте ширины `1440`, `768`, `390` и `375` px.
5. Сделайте собственные полностраничные снимки desktop и mobile и сравните с макетом `03_FINAL` в Figma.

Стили `css/style.css` и скрипт `js/script.js` уже подключены в `index.html`; сборка, npm и платные API не требуются.

## Проверка и ограничения

В отдельном браузерном QA-прогоне **выполнены** проверки рендера для ширин `1440, 1100, 850, 768, 600, 390, 375, 360, 320px`: нет горизонтального переполнения и обнаруженного обрезания текста; совпадают радиусы результата и чек-листа; все семь шаблонов выбираются; генерация/очистка промпта работают, мобильное меню открывается.

**Ограничение среды проверки:** браузерный контейнер блокирует прямые навигации `file://` и `http://localhost`. Поэтому для QA использован Chromium с загрузкой тех же локальных `index.html`, CSS и JS как отдельных текстовых ресурсов (`set_content`, затем `add_style_tag` / `add_script_tag`). Это подтверждает поведение и отображение **самого кода**, но не заменяет проверку на ПК через Live Server и на настоящем телефоне. Буфер обмена в реальном браузере зависит от разрешений контекста; предусмотрен запасной вариант выделения текста + Ctrl+C.

**Что не делалось:** публикация production-сайта, серверная обработка файла, добавление нового ИИ API, сборка полноценного backend. Созданный учебный проект не связан с `2md13.ru`.
