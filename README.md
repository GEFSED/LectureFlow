# LectureFlow · Практическая работа № 6

Конструктор собирает учебный промпт по выбранному материалу и одному из семи шаблонов. Выберите шаблон, укажите тип материала и нажмите «Сформировать промпт». Файл можно отдельно приложить к запросу во внешней нейросети.

## Запуск

Откройте корень этой ветки в VS Code. С расширением Live Server выберите **Open with Live Server** для `index.html`. Для запуска через Python выполните команду в каталоге сайта.

~~~powershell
python -m http.server 8000 --bind 127.0.0.1
~~~

Откройте <http://127.0.0.1:8000/>. Для телефона с авторизованной USB-отладкой выполните на ПК `adb reverse tcp:8000 tcp:8000` и откройте тот же адрес в Chrome Android. Снять созданное перенаправление можно командой `adb reverse --remove tcp:8000`.

## Откуда берутся карточки

HTML содержит форму, пустой контейнер карточек и элементы для состояний загрузки. Скрипт загружает `data/data.json` и проверяет HTTP-ответ, типы полей, уникальность ID и допустимые параметры формы. Поиск по заголовку приводит текст к нижнему регистру и нормализует пробелы. Категория и запрос действуют одновременно. Кнопки «Подробнее» и «Выбрать» получают исходную запись по ID.
